# Hangman Word Guessing Game (Console)

A modular, terminal-based Hangman game built in Python as part of the internship curriculum.

## 📝 Features
- Random word selection from an external `words.csv` file.
- Visual ASCII gallows art updating with every incorrect guess.
- Tracks guessed letters to prevent repeat penalties.
- Limited to 6 incorrect attempts before game over.
- Clean and interactive console UI.

## 🛠️ Prerequisites
- Python 3.x installed on your machine.
